# Revenue Analyst Portfolio

Two hotel revenue analytics case studies using synthetic data. Each includes an editable Excel workbook, CSV data, Power BI DAX measures, and instructions to build the dashboard in Power BI Desktop.

| Case study | Business question | Validation total |
| --- | --- | --- |
| [Hotel Revenue Performance](hotel-revenue-kpis.md) | How do occupancy, ADR, and RevPAR explain room revenue versus budget? | $685,269 room revenue |
| [Hotel Booking Pace and Pickup](hotel-booking-pickup.md) | Which stay dates are gaining bookings, and where is there still inventory to sell? | 294 net room nights picked up over seven days |
